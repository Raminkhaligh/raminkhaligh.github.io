The TL;DR: We mapped the onboarding funnel into discrete stages (Registration → KYC → Deposit → Trade) and used WebEngage to send targeted, A/B-tested nudges to users stuck at each gate. Churn dropped 6%, and transaction commissions grew 14%.

01. The Problem Space

The Leaky Funnel and the Dormant Base

Acquiring a crypto user is expensive. Losing them mid-funnel for lack of guidance is a costly, avoidable failure.

Our exchange had a clean UI, but user behavior stayed fragmented. A large share of registered users stalled: some signed up but never finished KYC; others finished KYC but hesitated before their first Rial or crypto deposit. The database kept filling with dormant accounts: users with real intent, stuck in limbo.

Manual marketing blasts made this worse, not better. Sending a "Complete your KYC" email to someone who had already deposited eroded trust instead of building it. We needed a system that knew exactly where each user stood in the funnel and delivered the right message, on the right channel, at the right time.

02. The Strategy

Architecting the Activation Pipeline

Full-Funnel Lifecycle Orchestration

We moved from broad, one-size-fits-all campaigns to a precise, event-driven lifecycle strategy built on WebEngage.

The goal: break the user journey into sequential gates: Registration → KYC → Deposit → Trade. If a user didn't clear a gate within a set window, the system intervened automatically with cross-channel messaging and tailored offers.

03. The Architecture

Building the Lifecycle Engine

This wasn't a tool swap. We rebuilt the data pipeline so backend events mapped directly to automated routing decisions.

Step 1 — The Linear Activation Flow

Strict event tracking classified every user into one of three states: Registered (no KYC), KYC verified (no deposit), or Deposited (no trade).

Step 2 — Omnichannel Nudges

If a user paused at any step (verified but no deposit within 24 hours, for example), WebEngage triggered a contextual nudge: Web Messaging for active sessions, push notifications otherwise.

Step 3 — A/B Testing on Messaging

We didn't guess at copy. WebEngage's A/B testing let us pit messaging angles (speed, security, opportunity cost) against each other and keep only what lifted conversion at each bottleneck.

Step 4 — The Dormant Win-Back Engine

The biggest opportunity was the dormant base. For users inactive 30+ days post-deposit, we automated fee-discount and targeted-offer journeys that brought them back without any manual outreach.

05. The Outcomes

The Business Impact

Turning static, manual outreach into an event-driven system extracted real value from a base we'd otherwise have written off.

+14% Commissions

Reactivating dormant users and guiding them past the initial deposit hurdle lifted platform trading commissions by 14%.

-6% User Churn

Mapping drop-off points (abandoned KYC, empty wallets) and firing timely interventions retained 6% of users who would otherwise have churned.

Continuous Uplift

Systematic A/B testing of messages and offers built a compounding optimization loop that scales without added manual work.
